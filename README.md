# Monte-Carlo-Option-Pricing-in-VBA-GBM-Exotic-Options-Structured-Products
Monte Carlo pricing in Excel/VBA: GBM path simulation, vanilla and exotic options (Asian, lookback) and a Worst-Of certificate on three correlated assets. (MANU, JUVE, ENEL)
## Overview

This project implements Monte Carlo option pricing entirely in Excel with VBA, progressing from basic path simulation to exotic options and a multi-asset structured product. It is Report 6 of the A.Y. 2025-2026 coursework. All simulations use the exact log-normal discretisation of Geometric Brownian Motion under the risk-neutral measure (S₀ = 1,000, K = 998, r = 1%, σ = 20%, T = 2 years, daily step), with Gaussian draws generated by the Box-Muller transform applied to VBA's `Rnd()`.

**GBM paths.** 100 trajectories are simulated and plotted in an embedded Excel chart, showing how the log-normal fan widens with σ√T while the median follows the risk-free drift.

**Vanilla pricers.** European calls and puts are priced with three approaches: a one-step terminal-price sampler with antithetic variates, a multi-step scheme, and a closed-form GBM step. Each is reported with its standard error and compared against the Black-Scholes benchmark. The number of simulations and steps can be set by the user, and the residual differences are consistent with Monte Carlo noise.

**Exotic options.** Arithmetic Asian options are cheaper than vanillas because averaging lowers effective volatility (≈ σ/√3). Floating-strike lookback calls and puts track the running minimum and maximum of each path and are compared with the Goldman-Sosin-Gatto closed form. Discrete monitoring introduces a known bias that shrinks as the number of steps grows.

**Worst-Of certificate.** A 3-year Maxi Cash Collect on Juventus, Manchester United and Enel is priced using volatilities and correlations estimated from two years of Refinitiv daily data, with correlated paths generated through a Cholesky decomposition. The product has an unconditional initial coupon, quarterly conditional coupons with memory effect, a coupon barrier, a capital barrier and an autocall trigger at 100%. The Monte Carlo fair value is about €79.80 per €100 notional (standard deviation ≈ €1.13), which implies an issuer margin at inception.

**Skills demonstrated:** stochastic simulation, variance reduction, path-dependent derivatives, Cholesky-based correlation modelling, structured-product valuation, VBA.
